通勤手当に税金はかかるのか ―― 4つの制度で扱いが違う

通勤手当は、所得税の世界では給料になりません。社会保険の世界では給料になります。1つの手当が、制度ごとに違う扱いを受けています。

「非課税だから、いくらもらっても引かれない」は、半分だけ当たっています。所得税については当たっています。社会保険料については外れています。

まず所得税 ―― 限度額までは非課税

所得税法9条1項5号が、通勤手当を非課税所得に並べています。

非課税になるのは、条文の言葉で「一般の通勤者につき通常必要であると認められる部分として政令で定めるもの」です。金額は、所得税法施行令20条の2が決めています。

条文には、見落としやすい条件がもう1つ入っています。「通常の給与に加算して受ける通勤手当」であること、です。

基本給に含めて払われている通勤費は、加算して受けたものになりません。求人票に「交通費込み」と書いてある給与は、ここに引っかかります。

電車・バス通勤 ―― 月15万円まで

交通機関を使う人の限度額は、1か月あたり15万円です（所得税法施行令20条の2第1号・第4号）。

金額の基準は、実際に払った額ではありません。条文は「最も経済的かつ合理的と認められる通常の通勤の経路及び方法」による運賃または定期券の価額と書いています。

新幹線や特急の料金も、経路と方法が経済的かつ合理的と認められれば、非課税の枠に入ります。グリーン料金は入りません。 国税庁のタックスアンサーが明記しています。

マイカー通勤 ―― 片道の距離で決まる

マイカーや自転車で通う人の限度額は、片道の通勤距離で決まります。

  • 2km未満 … 全額課税
  • 2km以上10km未満 … 4,200円
  • 10km以上15km未満 … 7,300円
  • 15km以上25km未満 … 13,500円
  • 25km以上35km未満 … 19,700円
  • 35km以上45km未満 … 25,900円
  • 45km以上55km未満 … 32,300円
  • 55km以上65km未満 … 38,700円
  • 65km以上75km未満 … 45,700円
  • 75km以上85km未満 … 52,700円
  • 85km以上95km未満 … 59,600円
  • 95km以上 … 66,400円

片道2km未満は、1円も非課税になりません。 近いほど有利に見えますが、逆です。

駐車場の料金を負担している人は、上の金額に駐車場等の料金相当額（上限5,000円）が足されます（同条第3号）。対象になる駐車場は、勤務する場所の周辺か、通勤に使う駅・停留所の周辺にあるものです。

⚠️ 金額を引用するときは、日付の表示を見てください。 限度額は改定されます。上の表は、国税庁タックスアンサー No.2585 が「令和8年4月1日現在法令等」として示している金額で、e-Gov法令検索の所得税法施行令20条の2の現行条文と一致しています。日付の無い解説には、古い金額が残っていることがあります。

限度額を超えた分は、給与になる

限度額を超えて支給された部分は、給与として課税されます。

国税庁は、超えた部分を「通勤手当や通勤定期券などを支給した月の給与の額に上乗せして」源泉徴収すると説明しています。パートやアルバイトでも、月を単位にして計算します。

社会保険 ―― 全額が「報酬」に入る

ここが、いちばん誤解されている場所です。

健康保険法3条5項は、報酬をこう定義しています。「賃金、給料、俸給、手当、賞与その他いかなる名称であるかを問わず、労働者が、労働の対償として受けるすべてのもの」。厚生年金保険法3条1項3号も、同じ書き方です。

除かれるのは2つだけです。臨時に受けるものと、3か月を超える期間ごとに受けるものです。

毎月払われる通勤手当は、どちらにも当たりません。名称を問わないと条文が書いている以上、通勤手当という名前も理由になりません。

つまり通勤手当は、標準報酬月額の計算に入ります（記事10）。

月2万円の通勤手当がある人は、標準報酬月額を決める金額に、毎月2万円が乗っています。等級が1つ上がれば、健康保険料と厚生年金保険料の両方が上がります。所得税はかからないのに、社会保険料はかかります。

雇用保険 ―― こちらも入る

雇用保険法4条4項も、賃金を「名称のいかんを問わず、労働の対償として事業主が労働者に支払うもの」と定めています。

通勤手当は、雇用保険料の計算のもとになる賃金に入ります。

残業代の土台 ―― ここだけ外れる

労働基準法37条5項は、割増賃金の基礎となる賃金から、家族手当と通勤手当を名指しで外しています。

だから通勤手当は、残業代の単価を上げません。記事8で書いた「外せる7つ」のうちの1つです。

ただし、判断されるのは名前ではなく中身です。通勤距離に関係なく全員へ一律に配っている「通勤手当」は、通勤手当として外すことができません。

4つ並べると、こうなる

  • 所得税・住民税 … 限度額まで非課税（所得税法9条1項5号）
  • 健康保険・厚生年金 … 全額が報酬に入る（健康保険法3条5項、厚生年金保険法3条1項3号）
  • 雇用保険 … 全額が賃金に入る（雇用保険法4条4項）
  • 残業代の土台 … 外れる（労働基準法37条5項）

1つの手当が、4つの制度で3通りの扱いを受けています。

住民税を所得税と同じ側に置いたのは、地方税法313条2項が、所得の計算を「所得税法その他の所得税に関する法令の規定による……計算の例により算定する」と定めているからです。所得税で非課税の通勤手当は、住民税でも所得に入りません。

転職のときに効いてくるところ

求人票の「月給」に通勤費が含まれているかどうかで、手取りが変わります。

同じ額面26.5万円の2社を並べます。

  • A社 … 月給25万円 ＋ 通勤手当1.5万円
  • B社 … 月給26.5万円（交通費込み）

所得税と住民税の対象は、A社が25万円、B社が26.5万円です。A社のほうが手取りは多く出ます。

社会保険料は、どちらも26.5万円が報酬なので同じです。

ところが、残業代の土台は逆になります。A社は通勤手当が外れて25万円。B社は交通費込みの基本給なので、外せる手当がなく26.5万円です。残業の多い職場なら、B社のほうが残業代の単価は高く出ます。

どちらが得かは、残業時間で入れ替わります。 額面だけを並べても答えは出ません。

今夜、確かめられること

給与明細を1枚出して、通勤手当が独立した行になっているかを見てください。

独立した行があれば、金額を上の表と15万円に照らします。超えていれば、超えた分は課税されています。

行が無ければ、通勤費は基本給に混ざっています。非課税の枠を1円も使えていない状態です。 混ざっているかどうかは、雇用契約書か求人票の「月給」の欄でも分かります。

マイカー通勤の人は、自宅から職場までの片道距離を地図で測ってください。2km未満なら、通勤手当は全額が課税されています。

社会保険料のほうは、明細を見ても分かりません。通勤手当を含めた金額で等級が決まっているとだけ覚えておけば足ります。4月・5月・6月の通勤手当が、その年9月からの保険料に効きます（記事10）。
